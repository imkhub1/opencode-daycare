## Confirmed Product Decisions

- One complete spec, not two separate specs.
- Active `staff` and `admin` users can invite parents for active children in their own daycare.
- Any child profile uses its UUID route; archived children cannot receive invitations.
- Persist the reference many-to-many model with `parent_children` and `invitations`.
- Persist `relationship_type` as `father`, `mother`, or `guardian`; translate to Spanish in the UI.
- Persist `invitation_status` as `pending`, `accepted`, `expired`, or `cancelled`.
- Generate a random, single-use, five-character token using an unambiguous uppercase alphabet; store only a secure hash.
- Token lifetime is seven days, and retries do not regenerate or extend it.
- Reject pending duplicate invitations and already-linked email/child pairs before sending.
- Use a separate delivery state (`sent`/`failed`) so a failed Resend request remains retryable without a duplicate row.
- Use the Resend Node SDK only from server-side code with configurable `RESEND_API_KEY`, `RESEND_FROM_EMAIL`, `NEXT_PUBLIC_APP_URL`, and optional `RESEND_REPLY_TO`.
- Show the generated token to staff and include it with the activation link in the email.
- `/activate?code=...` supports both the link and manual token entry; the invited email is read-only and the name is editable.
- New users use Supabase `signUp` with email confirmation, are created as `parent/pending`, and become active only after confirmation plus invitation acceptance.
- Existing parent accounts follow an explicit login branch before accepting the invitation.
- Add `/auth/callback` using Supabase SSR PKCE exchange and preserve the invitation token through confirmation.
- Acceptance is transactional and idempotent for the same user/token; it never creates duplicate links.
- After either new-account or existing-account acceptance, sign out and redirect to `/login?activation=success` with a visible message.
- Include retry inside the modal and a recovery action on the failed invitation card; do not add standalone cancellation or invitation-management screens.
- Require Supabase email confirmation, PKCE, and the callback URL in Auth Redirect URLs.
